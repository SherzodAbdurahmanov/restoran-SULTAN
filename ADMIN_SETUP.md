# Настройка админ-панели Sultan Restaurant

## Структура базы данных

Были созданы следующие таблицы:

### 1. `profiles`
Хранит информацию о пользователях и их ролях.
- `id` - UUID пользователя (связан с auth.users)
- `email` - Email пользователя
- `role` - Роль пользователя ('admin' или 'user')
- `created_at` - Дата создания профиля
- `updated_at` - Дата последнего обновления

### 2. `menu_items`
Хранит информацию о блюдах меню.
- `id` - UUID блюда
- `name` - Название блюда
- `description` - Описание блюда
- `price` - Цена блюда
- `category` - Категория блюда (salads, soups, main, mangal, pizza, pasta, desserts, drinks)
- `image` - Путь к изображению блюда
- `is_available` - Доступно ли блюдо для заказа (boolean)
- `created_at` - Дата добавления блюда
- `updated_at` - Дата последнего обновления

## Безопасность

Все операции защищены на уровне базы данных с помощью Row Level Security (RLS):

- Только администраторы могут изменять статус блюд
- Обычные пользователи не могут изменять роли
- Все пользователи могут просматривать доступные блюда
- Защита работает на уровне БД, а не только UI

## Создание первого администратора

### Шаг 1: Зарегистрировать пользователя

1. Откройте Supabase Dashboard: https://supabase.com/dashboard
2. Выберите ваш проект Sultan Restaurant
3. Перейдите в раздел "Authentication" → "Users"
4. Нажмите "Add user" → "Create new user"
5. Введите email и пароль для администратора
6. Нажмите "Create user"

### Шаг 2: Назначить роль администратора

1. В Supabase Dashboard перейдите в "SQL Editor"
2. Выполните следующий SQL-запрос (замените `admin@sultan.restaurant` на email вашего администратора):

```sql
UPDATE profiles
SET role = 'admin'
WHERE email = 'admin@sultan.restaurant';
```

3. Или создайте пользователя и назначьте роль одним запросом:

```sql
-- Сначала создайте пользователя через Auth UI, затем выполните:
UPDATE profiles
SET role = 'admin'
WHERE email = 'admin@sultan.restaurant';
```

### Альтернативный способ (через SQL)

Можно создать администратора полностью через SQL:

```sql
-- 1. Вставить пользователя в auth.users (требуется права суперпользователя)
-- Обычно делается через Supabase Dashboard

-- 2. После создания пользователя через Dashboard обновить роль:
UPDATE profiles
SET role = 'admin'
WHERE email = 'ВАШ_EMAIL@example.com';
```

## Вход в админ-панель

1. Откройте сайт: `/admin-login`
2. Введите email и пароль администратора
3. После успешного входа вы будете перенаправлены на `/admin`

## Возможности админ-панели

### Управление наличием блюд
- Просмотр всех блюд из базы данных
- Включение/выключение доступности блюд
- Фильтрация по категориям
- Поиск по названию и описанию
- Статистика (всего блюд, доступно, недоступно)

### Защита
- Ссылка на админ-панель отображается только для администраторов
- Прямой доступ к `/admin` без авторизации перенаправляет на `/admin-login`
- Обычные пользователи не могут получить доступ к админ-панели
- Все изменения защищены RLS политиками

## Миграция данных меню

Текущие данные меню из статических файлов нужно мигрировать в базу данных:

### Автоматическая миграция (рекомендуется)

1. Создайте скрипт миграции или используйте уже созданный `src/utils/migrateMenuData.ts`
2. Выполните миграцию через консоль браузера или создайте отдельную страницу

### Ручная миграция через SQL Editor

Или добавьте блюда вручную через SQL Editor в Supabase:

```sql

  ('Султан', 'Фирменное блюдо ресторана', '320сом', 'main', '/sultan.png', true);
-- Добавьте остальные блюда...
```

## Проверка работы

1. Войдите как администратор
2. Попробуйте отключить несколько блюд в админ-панели
3. Откройте страницу меню - отключенные блюда должны показывать статус "Нет в наличии"
4. Попробуйте добавить отключенное блюдо в корзину - кнопка должна быть неактивна
5. При оформлении заказа система проверит доступность всех блюд
6. Выйдите из системы - ссылка на админ-панель должна исчезнуть

## Устранение проблем

### Не удается войти в админ-панель
- Проверьте, что пользователь создан в Supabase Authentication
- Убедитесь, что роль 'admin' назначена в таблице profiles
- Проверьте правильность email и пароля

### Не отображается ссылка на админ-панель
- Убедитесь, что вы вошли в систему как администратор
- Проверьте роль пользователя в базе данных

### Не удается изменить статус блюда
- Проверьте RLS политики в Supabase
- Убедитесь, что функция `is_admin()` работает корректно
- Проверьте консоль браузера на наличие ошибок
